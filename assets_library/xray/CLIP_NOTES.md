# 클립 주의사항 — 고르기 전에 여기부터 (2026-09-23)

원고 에이전트들이 **프레임을 직접 뽑아 확인하다 찾아낸 것들.** 이름만 보고 고르면 틀리는 클립과,
구간을 잘못 잡으면 엉뚱한 부위가 켜지는 클립을 모아둔다. 새로 발견하면 여기에 줄을 추가할 것.

## 이름과 내용이 다른 클립

| 클립 | 이름에서 기대하는 것 | 실제 |
|---|---|---|
| `act_check_skin` | 피부를 살피는 동작 | 그냥 고개 숙인 자세, 발만 점등 |
| `m_growth_arrest` | 성장·발육이 멈춤 | **무릎 관절/성장판** 영상 |
| `m_follicle_weakening` | 난포(난소) 약화 | **모낭**(탈모) |
| `m_backflow_pooling` | 역류 전반 | **판막 있는 정맥에 적혈구가 고임**(하지정맥류 전용) |
| `m_sensory_mismatch` | 감각 불일치(어지럼) | 세포 덩어리 + 입자, 감별에 안 맞음 |
| `m_pump_failure` | 종아리 근육 펌프 | 방광형 주머니 |
| `m_keratin_thickening` | 모발 케라틴 | 각질층 단면(피부) |

## 구간을 잘라 써야 하는 클립

- `act_toss_turn` — **5.0초를 넘기지 말 것.** 5.2초부터 뇌가 점등해 불면 클립이 된다(누운 자세는 3.4~5.0초).
- `act_touch_neck` — **2.6초부터 갑상선이 점등**한다. 목 통증·삼킴 용도로 쓰려면 그 앞을 쓸 것.
- `m_eye_elongation` — 3.2초는 안구 벽 링만 보인다. **쓸 구간은 0~1.5초.**

## 부위 클립을 새로 만들 때

`scripts/make_part_clip.py`는 `--region`을 **안 주면 피사체 전체**가 호박색으로 켜진다. 전신·몸통
스틸은 region 필수 — 안 주면 몸 전체가 노래져 어디가 문제인지 안 보인다(2026-09-23 `part_kidney`
실측, 전신이 통째로 켜진 채 영상에 들어갔다). 장기 클로즈업 스틸(손톱·입술·눈꺼풀 등)은 생략해도 된다.

## 부위 클립 — region 없이 만들어 전체가 켜졌던 것들

`--region` 없이 만들면 피사체 전체가 호박색이 돼 **어디가 문제인지 안 보인다.** 아래 셋은
2026-09-23에 실제 영상에 들어간 뒤 프레임 검수에서 잡아 다시 만들었다.

| 클립 | 증상 | 고친 region |
|---|---|---|
| `part_kidney` | 전신이 통째로 노랗게 | `0.32,0.26,0.36,0.14` |
| `part_uterus_ovary` | 몸통 전체가 노랗게(간·신장까지) | `0.26,0.40,0.48,0.22` |
| `part_scalp` | 두피 블록 전체가 노랗게 | `0.12,0.14,0.76,0.32` |

⚠️ `part_bladder`도 골반 전체가 켜진다 — 쓸 일이 생기면 같이 고칠 것.

## 실패작

- `part_skin` — 피부 3층 단면인데 **전체가 호박색**이라 형태가 안 보인다. 위쪽 칸에 쓰지 말 것.
