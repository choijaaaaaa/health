# 클립 주의사항 — 고르기 전에 여기부터 (2026-09-23)

원고 에이전트들이 **프레임을 직접 뽑아 확인하다 찾아낸 것들.** 이름만 보고 고르면 틀리는 클립과,
구간을 잘못 잡으면 엉뚱한 부위가 켜지는 클립을 모아둔다. 새로 발견하면 여기에 줄을 추가할 것.

## 이름과 내용이 다른 클립 → 🚨 `lib/clip_index.py`가 정본이다

```bash
.venv/bin/python3 -m lib.clip_index --for 설사 복통     # 이 증상에 쓸 수 있는 클립
.venv/bin/python3 -m lib.clip_index --show m_vagal_slowdown
```

클립 하나하나를 **프레임으로 직접 보고** `seen`(화면에 실제로 보이는 것)과 `fits`(쓸 수 있는 맥락)를
적어둔 색인이다. 이름은 믿지 말고 여기서 찾아라 — 아래는 그중 특히 함정인 것들이고, 전체는 색인에 있다.

| 클립 | 이름이 말하는 것 | 실제 |
|---|---|---|
| `act_check_skin` | 피부를 살핌 | **무릎**을 짚고 무릎 관절만 점등 |
| `act_toilet_check` | 변 상태 확인 | 서서 **소변**보는 장면(방광→신장 점등) |
| `m_follicle_weakening` | 난포(난소) | **모낭**(탈모) |
| `m_growth_arrest` | 성장 정지 | **무릎 성장판** |
| `m_organ_ptosis` | 장기하수 | **골반저 근육**이 늘어짐(요실금 쪽) |
| `m_pressure_imbalance` | 막연한 압력 | **귀**(달팽이관·고막) |
| `m_backflow_pooling` | 역류 일반 | 판막 있는 **정맥에 적혈구가 고임**(하지정맥류) |
| `part_mouth_teeth` | 입·치아 | **두개골 전체**가 켜짐 |
| `part_spine_lumbar` | 요추 | **전신**이 통째로 켜짐 |

⚠️ **점등이 아예 없는 기전 클립**이 있다(`m_electrolyte_imbalance`·`m_fibrosis`·`m_layer_separation`·
`m_muscle_wasting`·`m_tissue_laxity`·`m_vision_field_loss`·`m_pressure_imbalance`). 호박색으로 부위가
켜지는 연출이 필요한 자리엔 못 쓴다.

⚠️ **품질 불량**: `act_rub_nose`는 점등이 없고 후반부에 인체 모델이 바뀌어 장면이 끊긴다.

## 구간을 잘라 써야 하는 클립

- `act_toss_turn` — **5.0초를 넘기지 말 것.** 5.2초부터 뇌가 점등해 불면 클립이 된다(누운 자세는 3.4~5.0초).
- `act_touch_neck` — **2.6초부터 갑상선이 점등**한다. 목 통증·삼킴 용도로 쓰려면 그 앞을 쓸 것.
- `m_eye_elongation` — 3.2초는 안구 벽 링만 보인다. **쓸 구간은 0~1.5초.**

## 부위 클립을 새로 만들 때

`scripts/make_part_clip.py`는 `--region`을 **안 주면 피사체 전체**가 호박색으로 켜진다. 전신·몸통
스틸은 region 필수 — 안 주면 몸 전체가 노래져 어디가 문제인지 안 보인다(2026-09-23 `part_kidney`
실측, 전신이 통째로 켜진 채 영상에 들어갔다). 장기 클로즈업 스틸(손톱·입술·눈꺼풀 등)은 생략해도 된다.

## 부위 클립 — region 없이 만들어 전체가 켜졌던 것들

`--region` 없이 만들면 피사체 전체가 호박색이 돼 **어디가 문제인지 안 보인다.** 아래 셋은
2026-09-23에 실제 영상에 들어간 뒤 프레임 검수에서 잡아 다시 만들었다.

| 클립 | 증상 | 고친 region |
|---|---|---|
| `part_kidney` | 전신이 통째로 노랗게 | `0.32,0.26,0.36,0.14` |
| `part_uterus_ovary` | 몸통 전체가 노랗게(간·신장까지) | `0.26,0.40,0.48,0.22` |
| `part_scalp` | 두피 블록 전체가 노랗게 | `0.12,0.14,0.76,0.32` |

⚠️ `part_bladder`도 골반 전체가 켜진다 — 쓸 일이 생기면 같이 고칠 것.

## 실패작

- `part_skin` — 피부 3층 단면인데 **전체가 호박색**이라 형태가 안 보인다. 위쪽 칸에 쓰지 말 것.

## 🚨 행위 클립은 동작이 디테일해야 한다 (2026-09-24)

사용자 지적: "영상도 동작이 디테일하게 잡혀들어가야 한다." 지금 라이브러리의 48종은 대부분
**뭉뚱그린 동작**이라 어느 병에 붙여도 같아 보인다 — `act_grab_belly`(배 움켜쥐기)는 위경련·장염·
생리통·과민성대장 어디에나 붙고, 그래서 어디에도 안 맞는다.

**그 병의 사람만 하는 동작**을 쓴다. 새 클립을 요청할 때 프롬프트에 아래를 반드시 적는다:

| 적을 것 | 나쁜 예 | 좋은 예 |
|---|---|---|
| **어디를 어떻게** 건드리는지 | "배를 만진다" | "명치를 주먹 관절로 누르고 몸을 앞으로 접는다" |
| **피하는 동작**(통증이 있으면 사람은 피한다) | — | "옷깃이 닿지 않게 팔을 들어 올린 채 옆구리를 비운다" |
| **반복의 리듬** | "긁는다" | "세 번 빠르게 긁고 멈췄다가 다시 두 번" |
| **무게중심·자세** | "서 있다" | "한쪽 다리에 체중을 싣고 반대쪽 골반이 내려간다" |

⚠️ 얼굴은 featureless라 표정을 못 쓴다. **통증·불편은 전부 몸으로** 드러나야 한다 — 어깨가 올라가고,
숨이 멈추고, 손이 가다 말고 멈칫하는 식.

⚠️ 동작이 곧 증상이어야 한다. 대상포진이면 **띠 모양 물집**이, 하지정맥류면 **도드라진 핏줄**이 그
동작 안에서 보여야 한다. 기존 클립에 그게 없으면 `clip_requests.json`에 적고 그 topic은 멈춘다.
