# 여기가 작업 자리다 — 다른 데 볼 필요 없다

```
작업/
  0_작업지시.md    ← 이것만 읽으면 된다. 번호·이름·프롬프트가 다 있다
  1_스틸/          ← 번호순 스틸. 미드저니로 새로 뽑은 것도 여기 같은 이름으로 넣는다
  2_완성클립/      ← Flow 결과를 **클립 이름 그대로** 여기 넣는다
  PHOTO_REQUESTS.md ← 사진 풀에 없어서 때운 품목 기록
  _지난것/         ← 끝난 시트 보관(볼 일 없다)
```

## 하는 순서

1. **`0_작업지시.md`를 연다.** 맨 위 표에 번호·이름·topic·스틸 유무가 있다.
2. **1부(스틸 있음)** — `1_스틸/`에서 같은 번호 파일을 Flow에 **start 프레임으로만** 넣고
   (end는 비운다), 시트의 그 번호 프롬프트를 붙여 뽑는다.
3. **2부(미드저니부터)** — 시트의 미드저니 프롬프트로 스틸을 먼저 뽑아 `1_스틸/`에 시트가
   적어준 이름(`18_act_....jpg`)으로 넣고, 그다음 Flow를 돌린다.
4. 결과 mp4를 **`2_완성클립/`에 클립 이름 그대로** 넣는다 (`act_inject_belly.mp4`).
   번호를 앞에 붙여도 받아준다.
5. 세션에게 말하면 끝 — 세션이 `scripts/collect_clips.py --commit`으로 라이브러리에 들이고,
   시트를 다시 만들고(남은 것만 1번부터), 그 topic들을 다시 조립한다.

## 규칙

- 🚨 Flow는 **start 프레임만** — end를 주면 Veo가 사이를 맞추려고 피사체를 변형시킨다.
- 길이는 **4·6·8·10초** 네 가지뿐. 기전(`m_`)은 4초 안에 컷 3개.
- 미드저니 레퍼런스: `act_`·`part_`는 **Omni Reference**, `m_`는 **Style Reference**
  (Omni 금지 — 클로즈업에 전신 인체가 끼어든다).
- 4장 중 1장 채택, 나머지는 `stills/_candidates/<이름>/`에 보관.
