# 계절별 건강 소재 캘린더

새 topic 시작할 때 참고할 월별 건강 카테고리 후보 목록. 이 문서는 참고용이지
강제 규칙이 아님 — 다른 좋은 소재가 있으면 그걸 우선해도 됨.

**트렌드 확인은 하루 한 번**: `python3 -m lib.trend_check --daily`를 그날 첫
작업 시 한 번 실행하면 아래 전체 키워드를 구글 트렌드로 조회해서
`data/trend_log.json`에 저장한다(같은 날 다시 실행해도 재조회 없이 기존 결과만
보여줌 — 30일 지난 데이터는 자동 정리). 그날 이미 실행했으면 그냥
`python3 -m lib.trend_check --show`로 저장된 결과만 확인하면 됨. 목록에 없는
키워드를 즉석으로 확인하고 싶으면 `python3 -m lib.trend_check <키워드1> ...`
(최대 5개, 로그에는 안 남음).

## 여름 (6~8월)
- 온열질환(열사병·일사병), 냉방병, 땀띠, 무좀·습진(다한증), 식중독, 장염,
  수족냉증(에어컨 과다 노출), 눈 다래끼(수영장), 자외선 관련(피부 트러블)

## 가을 (9~11월)
- 환절기 비염·감기, 알레르기(꽃가루), 건조증(피부·눈), 일교차 관절통,
  환절기 우울감, 환절기 탈모

## 겨울 (12~2월)
- 독감·감기, 동상·수족냉증, 안구건조증, 겨울철 우울감(계절성 정동장애),
  건조성 피부염, 노로바이러스, 심혈관 질환(한랭 자극), 실내 공기질(비염·기관지)

## 봄 (3~5월)
- 꽃가루 알레르기·비염, 春困症(춘곤증, 봄철 피로감), 미세먼지 관련 호흡기,
  환절기 감기, 새 학기 스트레스(수면 문제)

## 연중 상시(계절 무관, 다른 카테고리 소재 없을 때 폴백)
- 소화기(위염·역류성 식도염), 수면, 스트레스, 자세·거북목, 눈 피로, 구강 건강

## 사용 순서
1. `python3 -m lib.trend_check --show`(오늘 스냅샷 없으면 먼저 `--daily`)로
   전체 후보 모멘텀 확인
2. 이번 달에 해당하는 계절 절 + 위 모멘텀(▲)이 겹치는 카테고리 우선 — 기존
   topic과 `ls data/ | grep "^<카테고리>_"`로 중복 확인
3. 네이버 쪽 트렌드는 데이터랩/뉴스 API 준비 전까지 WebSearch로 수동 보완
   (예: "네이버 [카테고리] 검색량 최근" 식으로 검색해서 정성적으로 참고)
4. 급성 유행 이슈(감염병 등)는 계절 캘린더보다 우선 — 단, 정확성 요구가
   훨씬 높으므로 공식 출처(질병관리청 등)로 반드시 교차 확인 후 진행
