# 손싸개 (손싸개 늘 씌우기 → 손톱 짧게 정리 + 아기 손톱가위) — 원문 검증 팩트 (2026-10-14)

- 검색어: **손싸개**(월 3,190) · 보조 **신생아손톱**(620) — 코디네이터 제공, 이 세션에서 재측정 안 함.
- 바꿔 쓸 제품: **어른 손톱깎이(와 늘 씌운 손싸개) → 아기 손톱가위**(하나만). 카탈로그 `data/_audit/brandconnect_catalog_baby.json` 「아기 손톱가위」 chosen = 아가드 유아 위생용품 세트 7종 아기 손톱깎이 신생아 손톱가위 탕온계 손가락칫솔 핀셋(리뷰 1,244, 평점 4.86, link https://naver.me/x6Jyd7Zs). 품목명은 브랜드 없이 **"아기 손톱가위"**.
  - ⚠️ chosen이 7종 세트(손톱깎이·가위·탕온계 등)다. 대본·제목은 "아기 손톱가위"만 말한다. 코디네이터가 상품 사진에서 가위 날 끝이 둥근지 확인할 것(NHS 기준 "round-ended").
- 🚨 **손싸개가 발달을 해친다는 원문은 찾지 못했다**(EuropePMC "infant mittens" 계열 검색 0건 — 나온 건 오히려 'sticky mittens' 놀이 연구). 그래서 대본은 "손싸개가 해롭다"고 말하지 않는다. 사실 두 개(첫 달부터 손을 입으로 가져감 — AAP / 배고프면 주먹을 빪 — NHS)와 "손싸개를 늘 끼우면 손이 천에 싸여 있다"는 묘사까지만 쓰고, 해결의 중심은 NHS의 "손톱을 잘라라"다.
- 인용은 전부 `curl -A "Mozilla/5.0 (Macintosh…)"`로 받은 원문을 텍스트로 바꿔 문자열 대조했다. WebFetch 요약은 쓰지 않았다. 원문 사본은 세션 스크래치패드 `ev3537/`(임시).

  1. 긁는 건 손이 아니라 손톱
  2. 긴 손톱은 잘라 주기
  3. 첫 달부터 손을 입으로
  4. 손싸개는 잠깐만
  5. 아기 손톱가위로 바꾸기
  6. 잠든 틈에 자르기·손톱줄도 OK
  7. 날 끝 둥글고 작은 것
